# Security

## How to report security vulnerabilities

Report security issues privately, not in public issues or pull requests:

- Customers and partners: open a ticket in the Service portal at https://support.ibexa.co/.
- Everyone else: email security@ibexa.co (no account needed).

More details:

https://doc.ibexa.co/en/latest/infrastructure_and_maintenance/security/reporting_issues/
